# moda_austral

Prototipo web oficial para **Moda Austral** (tienda de vestuario, calzado y textiles reutilizados — Lenca & Puerto Montt).

## Estructura del Proyecto

- [`docs/`](./docs): Documentación de diseño (`DESIGN.md`), arquitectura (`ARCHITECTURE.md`) y presentación oficial del proyecto integrado (`Moda Austral_Unidad 2_Proyecto Integrado.pdf`).
- [`frontend/`](./frontend): Aplicación web desarrollada con **React 19 + TypeScript 5 + Vite 6 + Tailwind CSS v4**.

## Ejecución en Local

```bash
cd frontend
npm install
npm run dev
```

## Pruebas y Compilación de Producción

```bash
cd frontend
npm test
npm run build
```
